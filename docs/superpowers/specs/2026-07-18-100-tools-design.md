# FreeTools — 60 → 100 tools expansion

**Date:** 2026-07-18 · **Status:** approved, building

## Goal
Grow FreeTools from 60 to exactly **100** working, 100% client-side tools, and reorganize the whole catalog into clean, coherent categories. More tools = more SEO landing pages; a clean taxonomy improves navigation and search structure.

## Decisions (locked)
- Curate to exactly 100 (40 new tools), quality over raw count.
- Add new top-level nav categories; **reorganize all 100 tools** into 9 categories (retire the "Original Utility Suite" junk-drawer).
- OK to add ~6 tiny MIT client-side libraries, each dynamic-imported by the tool that needs it.
- Everything stays 100% client-side: no backend, no uploads, files never leave the device.

## The 40 new tools (curated)
Dropped as redundant: Video Muter (= Change Video Volume→0), Video-to-MP3 (covered). Added: Resize Image, Color Converter, HTML Entity Encoder, Unix Timestamp, QR Scanner.

- **PDF & Documents (+5):** delete-pdf-pages, reorder-pdf-pages, extract-pdf-text, extract-pdf-images, watermark-pdf
- **Video (+1):** video-to-gif · **Audio (+2):** audio-mixer, metronome
- **Image Tools (9 new):** image-cropper, resize-image, color-picker, color-converter, svg-to-png, exif-remover, image-invert, image-sharpen, image-grayscale
- **Developer & Data (10 new):** json-minifier, json-csv, base64, url-encode, html-encode, markdown-preview, jwt-debugger, xml-to-json, sql-formatter, unix-timestamp
- **Text Tools (8 new):** case-converter, word-counter, diff-checker, lorem-ipsum, slug-generator, find-replace, sha256-hash, md5-hash
- **Generators (5 new):** password-generator, uuid-generator, qr-code, barcode-generator, qr-scanner

## Category taxonomy (9 categories, all 100 tools)
1. **Video** (15) 2. **Audio** (10) 3. **Screen & Recording** (3) 4. **PDF & Documents** (22) 5. **Image Tools** (14) 6. **Developer & Data** (15) 7. **Text Tools** (11) 8. **Generators** (5) 9. **Design & Productivity** (5: svg-wave, css-keyframe, social-preview, invoice-generator, flashcards). Existing tools move via their `category` field (auto-updates sidebar, dashboard, sitemap).

## New dependencies
`qrcode` (QR gen), `jsqr` (QR read), `jsbarcode` (barcode), `sql-formatter`, `spark-md5` (Web Crypto lacks MD5), `diff` (text diff). All MIT, browser-side, dynamic-imported.

## Shared infrastructure (coordinator writes first)
- **TextTransformTool** shell — input textarea → transform fn → output + Copy/Download. Reused by ~18 text/dev tools (case, counter, slug, find-replace, base64, url, html, json-minifier, hashers, jwt, xml, sql, markdown, lorem, timestamp).
- **ImageCanvasTool** shell — dropzone → `<canvas>` pixel op → download. Reused by invert/sharpen/grayscale/crop/resize/exif/svg-to-png.
- Reuse existing: `lib/pdf.ts`, `lib/audio.ts`, `app/tools/_shared/use-ffmpeg.ts` + `video-workbench.tsx`, canvas patterns.

## Build approach
Phase 1 (coordinator): deps + shells + registry (9 categories, reorg 60, add 40 as `status:"soon"`) + generate stub pages → ship (100 tools visible, 40 "Soon"). Phase 2: ~6 parallel agents (disjoint tool dirs, per the proven playbook) implement the 40 real tools + content; coordinator flips to live, integrates, builds, deploys.

## Out of scope
No backend/accounts/premium; no redesign; existing 60 tools' behavior unchanged (only their category label moves).
